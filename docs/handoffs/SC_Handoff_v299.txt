CHANGES BUILT
Phone shell at <=768px: the sidebar becomes a drawer opened from a header menu
button. It closes on a destination, the Directory, the scrim, Escape or its
close control; it is inert while closed; focus moves in and back out. The
desktop sidebar state is separate and survives a resize.
Layers: page, badge + jump, scrim, drawer, modals. While the drawer is open the
content column sits under the scrim, so AR's sticky top bar no longer covers
the drawer. An open aria-modal dialog stays above the drawer.
Sales phone flow: both homes, Call Log list and detail, New Inquiry (Back/Next/
Save pinned, Close always visible on tall steps, 16px text entry including the
customer picker search box), Login 16px inputs.
Sales read lists: Proposals tabs wrap; Customer detail tables scroll inside
their frames; Leads, Invoices and Customers lists pass on the shell alone.
All new CSS is in src/styles/mobile-shell.css inside screen media queries at
<=768px or <=600px. Desktop markup changes are attributes and class names.

DECISIONS
Drawer and scrim keep z 70 / 60. Raising them above AR's z 100 header would
have put the drawer over sixteen z-100 modals, several in no-touch files, so
the content column is demoted while the drawer is open instead.
Log Outcome, job-list and Hunt results modals got role="dialog" aria-modal and
a name so that rule's modal exception covers them. Attributes only.
No P2 screen was deferred.
