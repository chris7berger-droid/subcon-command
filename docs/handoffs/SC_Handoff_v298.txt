DECISIONS
- Hold the App's state rather than move/remount Login mid-submit.
- Marker localStorage sc_recovery_user = verified user id while a reset is
  unfinished. Never a code or password. A password sign-in clears it.
- Refresh/return during an unfinished reset ENDS the recovery session (new
  code needed) rather than resuming it. Smaller and safe.
- Link recovery was broken on origin/main too (hash stripped before the
  client read it). Fixed here because links were in scope.
